# MiBiblioteca

Aplicación desarrollada en Flutter para gestionar una lista de lectura utilizando Provider

## Características

- Catálogo de libros.
- Agregar libros a una lista personal.
- Eliminar libros de la lista.
- Contador de libros seleccionado.
- Sincronización automática entre pantallas mediante Provider.

## Tecnologías

- Flutter
- Dart
- Provider

## Estructura

lib/
├── models/
├── screens/
└── main.dart

## Ejecución

1. Instalar dependencias

flutter pub get

2. Ejecutar la aplicación

flutter run
