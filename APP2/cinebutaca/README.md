# CineButaca

Aplicación desarrollada en Flutter para la reserva de asientos de cine utilizando Provider y Selector.

## Características

- Sala de cine de 6 filas por 8 columnas.
- Selección y deselección de asientos.
- Máximo 6 asientos por reserva.
- Cálculo automático del total a pagar.
- Confirmación de reserva.
- Optimización mediante Selector.

## Tecnologías

- Flutter
- Dart
- Provider

## Estructura

lib/
├── models/
├── screens/
└── main.dart

## Ejecución

1. Instalar dependencias

flutter pub get

2. Ejecutar la aplicación

flutter run
