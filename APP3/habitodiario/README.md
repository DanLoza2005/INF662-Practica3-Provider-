# HábitoDiario

Aplicación desarrollada en Flutter para el seguimiento de hábitos diarios utilizando MultiProvider

## Características

- Registro de hábitos.
- Clasificación por categorías.
- Marcar hábitos cumplidos.
- Cálculo automático del porcentaje de cumplimiento.
- Configuración de usuario.
- Tema claro y oscuro.
- Meta diaria personalizable.

## Tecnologías

- Flutter
- Dart
- Provider

## Estructura

lib/
├── models/
├── screens/
└── main.dart

## Ejecución

1. Instalar dependencias

flutter pub get

2. Ejecutar la aplicación

flutter run
